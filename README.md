# Sales Dashboard using Power BI

## Project Overview

This dashboard analyzes sales performance across product lines, cities, gender, and payment methods.

## Tools Used

- Power BI
- Data Visualization

## Dashboard Features

- Revenue by City and Gender
- Sales by Product Line
- Sales by Payment Method
- Monthly Sales Trend
- Interactive Filters
- Business Insights

## Key KPIs

- Total Sales: 322.97K
- Total Tax: 15.38K
- Quantity Sold: 5.5K
- Average Rating: 6.95

## Key Insights

- Food & Beverages generated the highest sales.
- Cash is the preferred payment method.
- Naypyitaw contributed the highest revenue.
- Average rating remained high across cities.
- Sales declined in February before recovering in March.
